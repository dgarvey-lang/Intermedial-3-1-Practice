# Capture the Flag: Systems of Equations (3-1 Practice)

An interactive practice game built from the 3-1 worksheet (solving systems of equations by graphing).

Open `index.html` in a browser to play.

- **Two teams, one screen** and **Solo practice** work anywhere the page is opened.
- **Live class game** relies on the Claude artifact runtime (shared database and sign-in), so it only works in the published artifact: https://claude.ai/artifact/3L3MRvbV3VFTzPeqT2zE65

# 3-1 Intermediate Practice (electronic worksheet)

`3-1-intermediate-practice.html` is the 3-1 worksheet (problems 1–13) as an interactive page.

- **Help** gives a hint, then more help, then the full solution.
- Using **More help** or the full solution means the student does a similar problem (up to 3) before moving on.
- When finished, students get a **teacher code** tied to their name. Open the page with `#teacher` at the end of the address (or click "Teacher: read student codes") to read one code or paste a whole class.
- **Restart worksheet** at the end erases the work on that device and starts a new attempt.
